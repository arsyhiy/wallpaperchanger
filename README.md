# обьяснение почему и как работает эта программа

## что делает программа?
главная и изначальная задача программы это менять обои в независемости где я.
современем везде где он нужен будет написан вариант адаптера.

## архитектура 
я решил разделить программу на две части:
- на графический интерфейс
- service или тот же backend

service это сердце программы он все делает что изначально делала эта программа.
service взаимодействует с gui черз ipc а точнее unix socket что можно поставить под вопрос 
так как unix socket не переносимая вещь и работает только unix подобных системах а у меня 
в планах использовать везде. значит надо будет както обдумать этот вопрос в будущем.

если говорить проще service -> ipc -> gui и обратно ipc фактически мост между ними

для взамодейсвтия используется json файл для простоты но может надо обдумать эту деталаь.

gui фактически просто черзе ipc отправляет внутри json комманды и получает также ввиде json 

я решил разделить gui и service что бы service Работал при запуске например gnome'а а gui 
в итоге был легким и простым в написании тоесть разделить зону что делает.

наверное если резумировать что нового: программа это теперь service и gui и взамодействую через ipc(unix socket)
